# AlphaSift source and translation provenance

This folder contains a complete, tracked-file snapshot of [ZhuLinsen/alphasift](https://github.com/ZhuLinsen/alphasift), with English documentation prepared for this trading lab. It is an ordinary directory, not a Git submodule, and contains no nested Git metadata.

- Upstream source commit: [`7639195e6176f4af37086c282834a7c09dc3e4a3`](https://github.com/ZhuLinsen/alphasift/commit/7639195e6176f4af37086c282834a7c09dc3e4a3).
- Local English translation commit: `b9a4176c142cef4d14dfd417bc0bd22e6257dd18`, prepared on the source checkout's `english-docs` branch.
- License: [Apache License 2.0](LICENSE), preserved from upstream.
- Original Chinese overview: [README.zh-CN.md](README.zh-CN.md), retained unchanged.

The translation changes 14 existing Markdown files, adds an English documentation index, and links that index from the project README. These are documentation modifications; source code, tests, strategy YAML, configuration files, commands, identifiers, numerical thresholds, and recorded sample results remain unchanged. Natural-language text and comments in documentation examples are translated; actual Chinese stock names, provider aliases, and sector-matching labels are retained where needed.

For inclusion in this repository, the documentation index's branch description has been adjusted to describe the snapshot, and this provenance file has been added. The root trading-lab README links to this folder.

Original upstream files are available at the linked source commit. To update this snapshot later, compare against that commit and preserve the English documentation changes explicitly. Upstream historical statements are translated as written rather than independently revalidated.

Start with the [English documentation index](docs/README.md).
